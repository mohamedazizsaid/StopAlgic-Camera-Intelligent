StopAlgic-Camera-Intelligent

camera intelligente pour detecter les anomalies dans une ligne de production du bouteilles

## 🚀 Fonctionnalités

### 🔍 Détection Intelligente
- **Détection d'anomalie** en temps réel
- **Analyse vidéo** avancée
- **Alertes automatiques**

- ### 🎯 Technologies Utilisées
- **OpenCV** - Traitement d'image et vidéo
- **YOLO/CNN** - Détection d'objets
- **Python** - Langage principal
- **TensorFlow/PyTorch** - Machine Learning

- ### Prérequis
- Python 10 ou supérieur
- Webcam ou caméra IP
- 4GB RAM minimum
